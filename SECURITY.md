# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in AuditGPT, please report it privately.

**Contact:** Nick Altstein — [nickaltstein@gmail.com](mailto:nickaltstein@gmail.com)

Please do not open a public GitHub issue for security-sensitive bugs or undisclosed vulnerabilities.

### Scope

- The AuditGPT CLI runner and test harness
- Test battery execution and reporting mechanisms
- Assertions and circuit breaker logic

### What to Include

- Description of the vulnerability
- Steps to reproduce or proof-of-concept
- Potential impact
- Any suggested mitigations

All reports will be acknowledged within 48 hours.
